## Overview

This is a fully functional catering application built with Flask. Users can create accounts, either being a Customer, Owner, or Employee. 
## Features

- **Account Functionality:** Users are able to create personal accounts to access the application
- **Customer page:** Customers are able to view available catering services and book them on specific dates
- **Owner page:** Owner account is able to manage employee scheduling and catering schedule
- **Employee page:** Employees can view the catering events they are assigned to
